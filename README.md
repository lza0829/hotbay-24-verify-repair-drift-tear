# 热档片间（Hotbay）

影院素材分区温层：登记 → 冷热迁移 → 保留销毁 → 目录互证。

- 前端 http://127.0.0.1:6300
- API http://127.0.0.1:11300
- `docker compose up -d --build`

## 漂移修补真源（全局唯一，不得混用）

互证发现键集合或字节指纹漂移时，一键修补**以在册素材段为准**：

- 按在册/已过期分区的素材段集合对齐湖对象行：缺失则**补齐湖对象行**、多出则**删除湖对象行**、字节不符则**对齐字节**；
- **在册素材段不因修补增删改**；
- 修补流水（`repair_runs`）逐键记录「对象键 · 问题 · 动作 · 前字节 → 后字节」，可重放；
- 修补在 `BEGIN IMMEDIATE` 事务内重算当前漂移后落锤，并发修补串行、同一回执凭 `UNIQUE(verify_run_id)` 只闭合一次，不会两边各删各的；
- 修正、流水、修后复证回执同事务提交，同成败；复证仍漂移则整体回滚，绝不只改漂移数字；
- 互证入口、修补入口、素材段表、湖对象行、修补流水、总览「当前漂移」徽章同刷闭合。

销毁是否连清目录清单属另一需求，保留销毁行为不在本口径内变更。

## 接口

- `POST /api/互证` — 跑一次互证，落漂移回执
- `POST /api/互证/{run_id}/修补` — 一键修补（以在册素材段为准）
- `GET /api/互证流水` / `GET /api/修补流水` / `GET /api/素材段清单` / `GET /api/目录清单`
